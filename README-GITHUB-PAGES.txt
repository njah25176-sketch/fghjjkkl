طريقة الرفع على GitHub Pages

1) فك ضغط هذا الملف.
2) ارفع الملفات الموجودة بداخله مباشرة إلى جذر المستودع:
   index.html
   .nojekyll
   attached_assets/hero-team.jpeg
3) من Settings ثم Pages اختر:
   Deploy from a branch
   Branch: main
   Folder: / (root)
4) افتح رابط GitHub Pages الذي يظهر لك بعد الحفظ.

مهم:
- لا ترفع ملف ZIP فقط.
- لا تضع index.html داخل مجلد إضافي.
- اسم الملف يجب أن يكون index.html بحروف صغيرة.
